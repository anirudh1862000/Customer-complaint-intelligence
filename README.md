## Data and responsible use
- Public complaint records are not a representative sample of all consumers; counts should be interpreted with context.
- Synthetic fraud and churn datasets are demonstrations, not real-world model results.
- Forecasting and inventory prototypes must not be described as validated production systems.
- Automated classifications and risk scores should support human review, not make final customer-impacting decisions.
- Numeric findings should be reported only after running the documented workflows and checking generated outputs.
